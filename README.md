# Taihei Yamaguchi

**Network Software Engineer | Mobile Core Networks & Linux Networking**

I develop and experiment with network software at the intersection of mobile core networks, protocol engineering, and Linux networking. I'm particularly interested in turning telecommunications standards and research ideas into working implementations and reproducible test environments.

## Areas of Interest

- **Mobile networks:** LTE/EPC, 5G Core, 3GPP architecture and protocols
- **Protocol engineering:** S1AP, NGAP, EPS/5GS NAS, GTP-U, PFCP
- **Linux networking:** SRv6, BGP, eBPF/XDP, packet forwarding
- **Development & validation:** C, Go, Linux, Docker, KVM/libvirt, network testing and automation

## Featured Projects

### [S1/N2 Gateway](https://github.com/Ytaihei/s1n2-gateway)

An experimental protocol-conversion gateway for connecting an LTE eNB to a 5G Core network. The project explores **S1AP–NGAP**, **EPS NAS–5GS NAS**, and **GTP-U** interworking, with a Docker-based development environment and deployment documentation.

### [free5GC SRv6 MUP Lab](https://github.com/Ytaihei/free5gc-srv6-mup-lab)

An experimental, reproducible 5G user-plane lab combining **free5GC**, **UERANSIM**, **BGP MUP**, **PFCP session observation**, and an **eBPF/XDP-based SRv6 data plane**. It includes documented test workflows and clearly tracks implementation limits and verification status.

### [Open5GS Compose](https://github.com/Ytaihei/open5gs-compose)

A Docker Compose environment for working with **4G EPC and 5G Core networks**, including RAN simulation options and integration with the S1/N2 Gateway.
